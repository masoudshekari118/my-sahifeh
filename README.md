# صحیفه سجادیه
گنجینه‌ای از دعاهای امام سجاد (علیه‌السلام) با ترجمه‌ای روان. اینجا می‌توانید بخوانید، جستجو کنید، هر بند را کپی کنید، برنامه مطالعه بسازید و پیشرفتتان را ببینید.

امکانات
جستجو در تمام متن‌های عربی و فارسی
فیلتر خوانده‌شده و خوانده‌نشده، و مرتب‌سازی بر اساس طول دعا
کپی یک‌کلیکی هر بند، با پشتیبانی کامل موبایل
تیک «خواندم» برای هر بند و ثبت خودکار پیشرفت
برنامه مطالعه با تقویم شمسی: انتخاب دعاها و تعداد روز
گزارش‌های نموداری از روزهای خواندن و پیشرفت
تنظیم اندازه و فونت متن عربی و فارسی و فاصله خطوط
حالت شب، طراحی ریسپانسیو و نسخه چاپی تمیز
